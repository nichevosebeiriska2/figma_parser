Figma Parser

Консольная утилита на **C++23** для парсинга, декомпрессии и конвертации внутренних данных файлов `.fig` (нативный формат Figma) в читаемый формат **JSON**. Создана как бесплатное
решение для чтения проприетарной системы сжатия figma файлов. Использовалась какое-то время для работы в составе системы автоматической сборки GUI прямо из Figma.  

Инструмент извлекает сжатые данные, декодирует внутренний бинарный формат сериализации Figma (известный как Kiwi) и сохраняет как схему данных, так и сами данные в виде структурированных JSON-файлов.

Все зависимости автоматически загружаются и собираются через систему `FetchContent` в CMake. Вам не нужно устанавливать их вручную:

- [ZLIB](https://github.com/madler/zlib) (v1.3.1) — для декомпрессии частей файла.
- [ZSTD](https://github.com/facebook/zstd) (v1.5.5) — для декомпрессии основных данных.
- [RapidJSON](https://github.com/Tencent/rapidjson) (v1.1.0) — для эффективной генерации JSON.

Системные требования

- CMake: версии `3.10` или выше.
- Компилятор C++: с полной поддержкой стандарта **C++23** (например, MSVC 2022, GCC 13+, Clang 16+).
- ОС: Windows (основная), Linux/macOS (при условии поддержки C++23 вашим компилятором).

Сборка проекта
	Проект настроен на полностью статическую линковку, чтобы итоговый исполняемый файл не требовал наличия внешних `.dll` (включая `vcruntime140.dll`).

Утилита разрабатывалась для использования через вызов shell/bash скрипта с передачей аргументов в .exe файл. 
.fig файл - это обычный переименованный .zip файл. Перед распаковкой нужно изменить расширение на .zip.
Подробнее о внутреннем формате figma файлов : https://github.com/evanw/kiwi

Пример вызова утилиты: FigmaToJson.exe "path_to_file" "output_dir(опционально)"
